# 🎵 MoodBeat AI - Smart Emotion Music Player, Ringtones & Downloader

MoodBeat AI is an intelligent, modern web-based music application that uses real-time facial emotion recognition to curate and play full-length songs according to your mood.

## ✨ Features
- 🎭 **Real-Time Facial Emotion Recognition**: Automatically scans mood using in-browser AI vision (Happy, Sad, Angry, Chill).
- 🎵 **100% Full Length Songs**: Unlimited 320kbps full track streaming without 30-sec preview cuts.
- 🔍 **Universal Search (40+ Songs)**: Search by any singer (Arijit, Shreya, Pawan Singh), actor (Salman, Shahrukh), or song title.
- 🔔 **Dedicated Ringtones & Caller Tunes Section**: Pre-cut ringtones with instant download.
- 📥 **Direct MP3 Downloader**: 1-click download songs & ringtones directly to device storage.
- 📱 **Mobile & Desktop Responsive**: Native app-like experience with 6 navigation tabs.
- ❤️ **Smart Playlists**: Liked songs are automatically segregated into their respective mood folders.

## 🚀 How to Run Locally

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the server**:
   ```bash
   python app.py
   ```
   Or double-click `run_app.bat` on Windows.

3. Open your browser:
   - **Local PC**: `http://localhost:5000`
   - **Mobile Phone** (Same Wi-Fi): `http://<your-ip>:5000`
